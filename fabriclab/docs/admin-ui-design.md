> 沿用用户端的三色与直角，按「样书」的排印逻辑重做信息结构。落地目录 `fabriclab/admin`，样式 `src/main/resources/static/css/admin.css`。
> 高保真原型：`docs/admin-ui-prototype.html`（单文件，五视图，顶栏切换中英，可直接打开）。
> 英文版规范：`docs/admin-ui-design.en.md`（不是本文的翻译，字号、字距、列宽按西文重设，见 6.12）。

> **V3 完成度整改（2026-11-14）**：原型经实际点检，v2 的「克制」被做成了「空缺」——0 张商品图、侧栏 0 图标、103 个可点元素里 91 个点了没反应。V3 补回图像、图标、品牌在场、操作密度与全部交互，见 **6.13**。6.13 与本文其余条款冲突时，以 6.13 为准。

## 一、设计主张

**后台即样书。** 服装品牌的后台不该长得像数据软件，它更接近一本内部样书：纸面铺底、以规则线与留白切分版面、文字承担层级、颜色只标示「此刻正在发生的事」。

由此推出六条执行原则：

1. **纸面，不是白盒。** 内容区是一整张纸（`#FBFAF7`），模块之间靠 1px 规则线与留白分隔。白色只给真正浮起的层——弹窗、Toast、下拉。上一版每个区块套白卡加描边，页面碎成十几个盒子，滚起来像电子表格。
2. **宋体负责叙述，无衬线负责操作，等宽负责数字。** 三者分工不混用：标题、区块名、空状态标题、弹窗标题用宋体；正文、表格、按钮、标签用无衬线；金额、件数、款号、日期、页码用等宽数字并开 `tabular-nums`。
3. **一个信号色，只标当下。** 陶土色 `#B4643A` 用于当前项、待处理状态点、破坏性按钮、焦点环、链接悬停。**V3 补充**：控制台主推横幅用一次大面积（约 3.5% 首屏面积），让品牌色真正在场；其余仍是墨与灰。上一版让主按钮悬停变橙、操作列整列变橙，强调色通胀后等于没有强调。
4. **抬升只给浮层。** 表格行、卡片、区块一律没有阴影。阴影出现即代表「这一层浮在纸面之上」，只有 `<dialog>` 和 Toast 配得上。
5. **每屏一个主行动。** 页头右侧最多一个实心墨色按钮，其余走描边或文字。行内操作常态只有一个「编辑」，`···` 悬停才出现。
6. **不显示未经查询的数字。** 任何计数、金额、件数必须来自当次 SQL。没有真实口径的指标（转化率、访客数、同比）不出现，宁可版面留白。

## 二、视觉语言

### 2.1 色彩

| 变量 | 值 | 用途 | 说明 |
|---|---|---|---|
| `--ink` | `#1A1A1A` | 主文字、侧栏底、主按钮底 | 与用户端同源 |
| `--ink-soft` | `#2E2C28` | 深色底上的次级文字 | — |
| `--paper` | `#FBFAF7` | 内容纸面、表头底 | **新增**：比纯白暖一档，长时阅读不刺眼 |
| `--canvas` | `#F0EDE6` | 页面最外层画布 | 只在内容区之外露出 |
| `--white` | `#FFFFFF` | 弹窗、Toast、下拉 | 唯一的纯白 |
| `--cream` | `#F2EFE9` | 深底上的文字、主按钮文字 | 同 |
| `--rust` | `#B4643A` | 信号色（见原则 3） | 同 |
| `--rust-ink` | `#9E532D` | 小字号强调（对纸面 5.0:1） | 加深一档以过 AA |
| `--rule` | `rgba(26,26,26,.11)` | 区块分隔、表格行线、注记分割 | **替代**上一版的 `--line` 实色描边 |
| `--rule-strong` | `rgba(26,26,26,.30)` | 页头底线、表头底线、输入框描边 | — |
| `--wash` | `#F4F1EA` | 行悬停、只读底 | — |
| `--wash-deep` | `#EBE7DD` | 图标按钮悬停、开关关闭态 | — |
| `--muted` | `#6E6961` | 次要文字（对纸面 5.1:1） | 任一尺寸可用 |
| `--faint` | `#8A8478` | 编号、时间、占位符（3.4:1） | **只用于非必要信息**，不承载操作 |
| `--body` | `#3A3833` | 长段落正文 | — |

深色侧栏专用：底 `--ink`，主文字 `rgba(242,239,233,.70)`，悬停 `.045` 底 + 文字 `.92`，分组标题 `.32`，分割线 `.10`。

**状态语义不用绿色。** 成功用墨色加勾形，进行中用陶土实心点，终止用 26% 灰实心点。四色体系够用，引入第五色会让「成功」抢走「待处理」的注意力。

### 2.2 字体

| 变量 | 字体栈 | 用途 |
|---|---|---|
| `--f-song` | `"Songti SC", "Noto Serif SC", "Source Han Serif SC", STSong, SimSun, serif` | 页面主标题、区块标题、空状态标题、弹窗标题 |
| `--f-body` | `"Inter", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif` | 正文、表格、表单、按钮、标签 |
| `--f-num` | `"Inter", "Helvetica Neue", Arial, sans-serif` | 金额、件数、款号、日期、页码，统一 `font-variant-numeric: tabular-nums lining-nums` |

**改动说明**：上一版数字用 Bahnschrift/DIN，Windows 上尚可，跨平台（macOS、Linux 服务器渲染 PDF）字形会跳。改用 Inter + Arial 兜底，靠 `tabular-nums` 保证列对齐——对齐是后台数字的第一需求，字形风格其次。

宋体只出现在标题层级，不进入正文与表格。中文宋体在 12–13px 下笔划过细，辨识速度不如黑体；放到 21px 以上则立刻显出印刷气质，这是全站气质的锚点。

| 13 | 400 | 1.6 | `.02em` | 侧栏导航、次要正文 |

阶梯比上一版整体上移一档（正文 13→14，标题 26→34）。上一版在 1440 屏上通篇 11–13px，密而不重，读起来像十年前的 B 端工具。

`--faint` 只用于 11px 以下的编号与说明，且不作为唯一信息载体。

### 2.4 版面格律

八级间距：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

| 项 | 值 |
|---|---|
| 内容最大宽 | 1440（上一版 1560，行长过宽） |
| 内容内边距 | `0 48 72`；<1280 `32`；<1024 `24`；<720 `20` |
| 页头 | `padding 36 0 22`，底部 `1px --rule-strong` |
| 区块 | 上 `1px --rule`，`padding-top 32`；编号列 44，正文缩进 44 |
| 主栏 / 注记栏 | `minmax(0,1fr) 300`，间隙 64，注记栏左 `1px --rule` + `padding-left 40` |
| 区块之间 | 32（含分割线） |
| 字段之间 | 24；同排两列间隙 24 |

**编号列是这一版新增的版式元件**：每个区块左上角一个两位数（`01` `02`），10.5px 等宽，颜色 `--faint`，与标题之间空 44。它把表单从「一堆输入框」变成有章节的文档，也是唯一允许出现 `--faint` 的地方。

### 2.5 描边、抬升、动效

- 描边一律 1px，颜色只用 `--rule`（分隔）与 `--rule-strong`（结构线、控件边）两级。不使用 2px 边框。
- 阴影仅两处：弹窗 `0 32px 80px rgba(26,26,26,.26)`、Toast `0 12px 32px + 1px 环`。**卡片、表格行不加阴影。**
- 动效：悬停 `.13–.16s ease`；位移用 `.2s cubic-bezier(.22,.61,.36,1)`；进度条 `1.1s` 走完。只动 `background / border-color / color / opacity / transform`。
- `prefers-reduced-motion: reduce` 下全部归零（落地时在 `admin.css` 末尾加一段 reset）。

## 三、布局结构

### 3.1 骨架

```
┌───────────────┬──────────────────────────────────────────────────┐
│               │  顶栏 60   面包屑 ······ 搜索 帮助 | 演示环境      │
│  侧栏 240     ├──────────────────────────────────────────────────┤
│  墨色         │                                                  │
│               │  ┌ 眉标 — 02 商品 ──────────────────────────┐    │
│  品牌区 72    │  │ h1 款号维护          [在册 60 款] [新增款号]│   │
│               │  └───────────────────────────────────────────┘    │
│  概览         │  ────────────────────────────────────────────────  │
│   控制台      │                                                  │
│               │  工具条   搜索 / 分段 / 重置                      │
│  商品         │  ────────────────────────────────────────────────  │
│   款号维护    │  表格（表头吸顶）                                 │
│   分类维护    │                                                  │
│   库存与相册  │  分页条                                          │
│               │                                                  │
│  顾客         │  ────────────────────────────────────────────────  │
│   账号管理    │  版权页脚                                        │
│               │                                                  │
│  交易         │                                                  │
│   订单管理    │                                                  │
│               │                                                  │
│  系统         │                                                  │
│   会话与安全  │                                                  │
│   操作日志    │                                                  │
│  ─────────    │                                                  │
│  账号 / 退出  │                                                  │
└───────────────┴──────────────────────────────────────────────────┘
```

- 外层 `height:100vh; display:flex; overflow:hidden`，侧栏与内容区各自纵向滚动。后台导航必须常驻。
- 侧栏 `240px` 固定；内容区 `flex:1; min-width:0`（`min-width:0` 是表格横滚不撑破布局的关键）。
- 编辑页与订单页底部有操作条时，操作条放在滚动容器**之外**（`.main` 之后），由 flex 让出高度，永不遮挡正文。不用 `position: sticky`。

### 3.2 侧栏

| 部分 | 规格 |
|---|---|
| 品牌区 | 高 72；30×30 纸色方块内嵌宋体「未」；主名 11.5px 字距 `.2em`；副名 `MANAGEMENT` 9.5px 字距 `.26em` 色 `.38` |
| 分组标题 | 上内边距 24 / 左右 20 / 下 8；9.5px 字距 `.24em` 色 `.32`；不可点击 |
| 导航项 | 高 36；左内边距 20；13px；默认色 `.70`；悬停底 `.045` + 色 `.92` |
| 当前项 | 左侧 2px `--rust` 竖条（上下各内缩 8）+ 文字 `--cream` |
| 底部账号 | 上边 `1px rgba(cream,.1)`；26×26 头像方块 14% 白底；显示名 11.5px；角色 `ADMIN` 9.5px 字距 `.14em`；右侧退出图标 |

**V3 恢复图标，但先统一几何语言。** v2 曾把导航图标全部删除，结果侧栏只剩一列灰字，扫描效率与完成度都下降。V3 用一套 `<symbol>` 图标库：16 格、1.4px 描边、圆头、无填充，八项各自不同但同一构造；常态 42% 透明度，当前项 95%。层级仍主要靠缩进、底色与字距，图标只做锚点。

### 3.3 顶栏

高 60，底 `--paper`，下边 `1px --rule`，左右内边距跟随内容区。

- 左：面包屑「商品 / 款号维护」，12px，`--faint` 分隔，末级 `--ink` + `aria-current="page"`。
- 右：搜索图标、帮助图标（34×34 热区，悬停底 `--wash`）→ 1px 竖线 → 环境标签「演示环境」（10px 字距 `.16em`，1px `--rule` 描边）。
- **账号不再重复出现在顶栏**：上一版顶栏右侧有「平台管理员 / ADMIN / 退出」，侧栏底部又有一套，两处信息完全相同。这一版只保留侧栏底部一处。
- 顶栏底部叠一条 1px 陶土进度条（`#progress`），只在跨页提交时 `scaleX` 从 0 走到 1，1.1s 后淡出。

## 五、页面规范

### 5.1 通用页头

```html
<div class="ph">
  <div>
    <div class="ph__eyebrow"><em>02</em>商品</div>
    <h1>款号维护</h1>
    <p>维护款号、面料工艺、价格与上架状态。库存不在这里直接改写，走补货入口。</p>
  </div>
  <div class="ph__act">
    <span class="ph__count">在册 <b>60</b> 款 · 在售 <b>54</b></span>
    <button class="btn">新增款号</button>
  </div>
</div>
```

- 眉标由「20px 短横线 + 两位章节号 + 模块名」组成，10.5px 字距 `.2em`。
- `h1` 宋体 34px，不写「管理」「列表」这类冗余后缀（`款号维护` 优于 `商品款号管理列表`）。
- 说明句只写「这页能做什么」与「哪些事不在这里做」，不写模块背景。
- 右侧：先计数索引（`ph__count`，11.5px，数字等宽），再主按钮。计数让页头承担「这是第几章、共多少条」的编辑信息，比只放一个按钮更有信息量。

### 5.2 控制台 `/admin/console`

四段结构：计数带 → 待处理（01）→ 最近上架（02），右栏三块注记。

- **计数带**：`grid 4 栏`，栏间 `1px --rule` 竖线，无外框。每栏 `padding 32 0 30`：
  - 指标名 10.5px 字距 `.18em` + 右侧英文缩写（`LIVE` `DRAFT` `≤3` `PAID`）+ 一条延伸到底的 `--rule` 细线，构成「表头」质感；
  - 数值 38px 等宽，用 `.stat__num` 包一层 `min-width:1.92ch`，让「54 款 / 6 款 / 3 款 / 2 笔」的单位落在同一条竖线上；
  - 脚注 11.5px `--faint`。
  - 四个口径：在售款数、草稿款数、库存 ≤3 的款数、待发货订单数，全部由 `COUNT` 得到。
- **待处理**：`grid 96 | 1fr | 84`，行高 76，行间 `1px --rule`，悬停整行 `--wash`。左列状态标记，中间主行 + 次行，右列「去发货 →」（悬停时箭头右移 3px）。无待办时整块换成空状态。
- **最近上架**：`grid 110 | 1fr | 76`，行高 60。时间（11.5px `--faint`）+ 款号（等宽 11.5px）+ 名称（13.5px）+ 状态。取 `ORDER BY updated_at DESC LIMIT 3`，与列表页同一查询条件。
- **右栏注记**（300px，左侧 1px 竖线）：运行状态（端口 / 前缀 / 超时 / CSRF / 数据库连接）、本次会话（登录时间 / 最近活动 / 来源）、说明。三块用 `aside-sec` 分隔，每块底部 1px `--rule`。
- 不放趋势图、不放销售额、不放「今日新增」。没有可核对的数据源就不画。

### 5.3 列表页（分类 / 款号 / 账号 / 订单共用骨架）

结构：页头 → 工具条 →（批量条）→ 表格 → 分页。

- **工具条**：`padding 26 0 0` + 底部 `1px --rule`，底线即分段器的选中线。
  - 搜索框：`280×38`，1px `--rule-strong` 描边，左内 12，放大镜 14px，聚焦时描边转墨 + 3px `rgba(26,26,26,.06)` 外环。
  - 分段器：文字 + 底部 1px 下划线，项间 26，`margin-bottom:-1px` 让选中线与工具条底线重合；每项后跟等宽计数（`全部 60` / `在售 54`）。
  - 右侧「重置筛选」为 12.5px 下划线文字。
  - **上一版搜索框用下划线式并留 `margin-bottom:20`，与分段器的下划线差 22px，两条线错开。** 这一版统一成 38px 高的框式，底边与分段器、工具条三条线合一。
- **批量条** `.bulk`：勾选 ≥1 行时出现在表头上方，`padding 13 0`，左「已选 3 项」，右「批量上架 / 批量下架 / 取消选择」。选中行整行底 `#F1ECDF`。
- **表格**：见 6.1。
- **分页条**：`padding 22 0 0`；左「共 60 条 · 第 1 / 3 页」（数字等宽）；右页码 + 每页条数（下划线式 `select`，10 / 20 / 50，默认 20）。

列定义：

| 列表 | 列（对齐） | 操作列 |
|---|---|---|
| 款号 | 勾选 40、款号 110(等宽)、名称/面料 auto、品类 120、价格 110(右)、库存 70(右)、更新 100、状态 86、操作 92 | 编辑 + `···` |
| 分类 | 编码(left)、名称(left，二级缩进 24 + 引导线)、层级(标签)、排序(右)、款数(右) | 编辑、删除 |
| 账号 | 用户名(left)、显示名(left)、邮箱(left)、状态、注册时间(右) | 编辑、重置口令、启停 |
| 订单 | 订单号(等宽,left)、收货人、金额(右)、状态、下单时间(右) | 详情、发货 |

### 6.12 双语实现

原型一个文件承载中英两版，顶栏右侧切换，即时生效、可来回切。

**三类节点。**

| 标记 | 存什么 | 例子 |
|---|---|---|
| 纯文本 | 中文原文，查字典替换 | `款号维护` → `Styles` |
| `data-en` | 单个英文字符串，替换该节点文本 | `2026.11.13` → `13 Nov 2026` |
| `data-en-html` | 英文标记，替换该节点内部 HTML | `共 <b>60</b> 条 · 第 <b>1</b> / <b>3</b> 页` → `<b>60</b> styles · page <b>1</b> of <b>3</b>` |

`data-en-html` 专为语序不一致的片段存在。把 `共`、`条 · 第`、`页` 三段分别翻译，会得到 "Total 60 of 1 page 3"——语法上不成立。整句必须整体替换。全站只有三处：页头计数、分页状态、批量条计数。

**回切靠记录，不靠回译。** 首次切换前记录每个中文文本节点的原串与前后空白，切回中文时原样写回，不经过英文再翻回来，因此反复切换不会累积偏差。

**属性一并处理。** `placeholder`、`aria-label`、`title`、`alt`、`value` 走同一套字典。其中 `value` 最容易被漏：商品名、面料描述、工艺说明都是输入框的属性值，不是子文本。

**不译的部分。** 款号（`FL-HM-01`）、订单号、支付凭证号（`MOCK…4C8A`）、路由、端口、`version` 计数是技术标识，两版完全一致，这也是它们统一用等宽字体的原因之一。

**切语言必须重渲染，不能只换字。** 面包屑由脚本写入，按当前语言从双语 `META` 表重取；批量条计数在每次切换后按复选框实际状态重算——`data-en-html` 会重建内部的 `<b>` 节点，旧引用会印出上一版语言的数字。

**两版不同的地方。**

| 项 | 中文版 | 英文版 |
|---|---|---|
| 衬线栈 | Songti SC / Noto Serif SC | Iowan Old Style / Palatino / Georgia |
| `h1` | 34px / `.015em` | 37px / `-.006em` |
| 全大写小标字距 | `.18em` | `.13em` |
| 表头 | 10px / `.14em` | 9.5px / `.10em` |
| 正文行高 | 1.65 | 1.68 |
| 侧栏宽度 | 240 | 254 |
| 品类列宽 | 120 | 134 |
| 日期 | `2026.11.13` | `13 Nov 2026` |
| 导航大小写 | — | Title Case |
| 计数标题 | 在售款号 / 草稿款号 | Published / Unpublished |

**为什么字距要改。** `.18em` 落在「商品」两个字上是舒展的气口，落在 "RUNTIME" 上会把词撕成五座孤岛。西文全大写的合理区段是 `.10–.14em`，所以每一处小标都单独收过，不是整体缩一档。

**为什么计数标题要改名。** 直译「在售款号」得到 "Live styles"，右侧状态码又是 `LIVE`，读作「Live styles LIVE」，说了两遍没多说一句。英文版换的是指标名，不是状态码：`Published` / `Unpublished`。

**为什么西文底衬线不用 Georgia 打头。** Georgia 的圆润碗形与旧式数字对一家在无涂布纸上印画册的品牌来说过于亲和。Iowan Old Style 与 Palatino 更接近编辑物的锐度，且分别覆盖 macOS 与 Windows，首选即是对的。

**不译即译。** 侧栏在英文版加宽 14px 容纳两词导航；按钮不设固定宽度，让英文自然撑开而不是挤成两行；日期改日在前，是国际运营者唯一无需解码的写法。

## 九、可访问性

1. 每页首个可聚焦元素是「跳到主要内容」，目标 `#main`。
2. 侧栏当前项 `aria-current="page"`；分组标题用 `<h2 class="side__group">` 构成大纲。
3. 表格 `<caption class="sr-only">` 说明数据范围；操作按钮写全「编辑 FL-HM-01」而非只有「编辑」。
4. 成功用 `role="status"` / `aria-live="polite"`，失败用 `role="alert"`。
5. 全部功能可键盘完成：Tab 顺序 = 侧栏 → 顶栏 → 内容；弹窗内 Tab 循环；ESC 关闭；行操作的 `···` 聚焦即显现。
6. 对比度：`--ink` 对纸面 16.4:1；`--muted` 5.1:1；`--rust-ink` 5.0:1；`--faint` 3.4:1（仅非必要信息）。`--rust` 只用于 ≥16px 文字或非文字元素。
7. 色卡 `alt` 写款号与名称，不写「图片」。窄屏隐藏的列，信息在详情页必须仍可查到。

### 6.13 V3 完成度整改

**为什么返工。** v2 的排印逻辑（纸面、规则线、章节编号）解决了第一版的廉价感，但连续三轮做减法，把「克制」做成了「空缺」。以真实操作路径点检后的证据：

| 指标 | v2 | 说明 |
|---|---|---|
| 真实图像 / 商品缩略 | 0 张，8 个纯色方块 | 一眼看出是占位符 |
| 侧栏图标 | 0 个 | 一列灰字，没有扫描锚点 |
| 品牌色面积 | 5 个 5px 小点 | 等于没用 |
| 可点元素 | 103 个，**91 个点击后无任何变化** | 号称高保真，实为可切换的静态画稿 |
| 表格数据 | 8 行硬编码 | 筛选、搜索、分页、批量全是摆设 |

用户感知到的「敷衍」不是配色问题，是**完成度问题**：界面停在线框稿阶段，每一处都像「还没填内容」。

**六条整改。**

1. **表面分层**：新增 `--surface:#FFFFFF` 工作带（顶栏、工具条、表头、批量条），与 `--paper` 纸面、浮层白构成三层。**连续横带，不是白卡片**——避免退回第一版「十几个盒子」。侧栏由纯黑转暖黑 `#211E1A` 并加 3px 陶土品牌带。
2. **品牌在场**：控制台加主推横幅（陶土渐变 + 大号宋体标题 + 主推款图像 + 四项事实），陶土色第一次有面积；当前导航项改陶土浅底 + 3px 竖条。
3. **图像与图标**：8 种服装廓形 SVG（高领衫 / 衬衫 / 围巾 / 外套 / 长裙 / 夹克 / Polo / 袜）× 3 配色，含明暗、织纹、缝线、罗纹、投影；侧栏与顶栏恢复统一 1.4px 图标库。
4. **操作可见**：状态方块 5→7px、文字回到正文字深；`···` 由「仅悬停可见」改为常态 55% 可见；顶栏补全局搜索（`/` 聚焦）、快捷新建、通知、账号。
5. **数据做实**：60 条双语商品数据（20 款 × 3 色），按更新时间交错排列，同款不连排；筛选、搜索、分页、每页条数、勾选、批量上架/下架、行菜单、编辑回填、删除弹窗、Toast、空状态全部可用；计数带与分段器计数由数据实时算出。
6. **诚实反馈**：每个可点元素都有可观察反馈。未实现的模块不假装跳转，明确说明「T13 起接入」；Toast 最多 3 条、4 秒收起、悬停暂停，切语言时清空（瞬时反馈不重译）。

**验证**：26 项端到端用例全过（搜索 / 筛选 / 翻页 / 每页条数 / 批量 / 行菜单 / 编辑回填 / 侧栏导航 / 发货 / 空状态 / 中英往返 / 820 与 420 无横向溢出）；无 JS 错误。原型打开即为可用状态，中英切换仍按 6.12 的三类节点机制工作。

**落地口径不变**：颜色、间距、组件尺寸与双语规则照旧；V3 新增的是 `admin.css` 里 `html[data-lang]` 之外的表面层与图标库，T13 实现时按 10.1 的类名清单追加即可。
