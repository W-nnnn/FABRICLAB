# FABRICLAB 后台管理界面设计规范

> 沿用用户端视觉语言，按管理台的信息密度重排。代码落地对应 `fabriclab/admin`，样式文件 `src/main/resources/static/css/admin.css`。
> 高保真原型：`docs/admin-ui-prototype.html`（单文件，可直接打开）。

## 一、定位与三条硬约束

后台不是用户端的缩小版。用户端是「看」，后台是「改」：同一套颜色与字体，密度更高、操作更常驻、结果更可预期。

三条不可破：

1. **不引入第四种色相**。全站只有墨 `#1A1A1A`、纸 `#F2EFE9`、陶土 `#B4643A` 三色及其明度派生。成功态不用绿色，用墨色加勾形；失败态用陶土色加叹号。
2. **保持直角**。用户端全站无圆角（`border-radius` 只用于圆点），后台同样不出现圆角卡片、圆角按钮、圆角标签。
3. **不显示未经查询的数字**。任何计数、金额、件数必须来自当次 SQL 查询；没有真实统计的口径（转化率、访客数、同比）一律不出现。

## 二、设计基线

### 2.1 颜色

| 变量 | 值 | 用途 | 与用户端 |
|---|---|---|---|
| `--ink` | `#1A1A1A` | 主文字、侧栏底、主按钮底 | 同 |
| `--cream` | `#F2EFE9` | 深色底上的文字、选中态文字 | 同 |
| `--wall` | `#EDEAE2` | 后台页面底色（比用户端纸色深一档，白卡才浮得起来） | 收敛 |
| `--rust` | `#B4643A` | 强调、进度、选中竖条、破坏性按钮 | 同 |
| `--rust-ink` | `#A0552F` | 小字强调（对纸色 4.77:1） | 同 |
| `--paper` | `#FFFFFF` | 卡片、表格、表单底 | 同 |
| `--line` | `#E3DDD2` | 卡片描边、表头下边、分页条上边 | 同 |
| `--hair` | `rgba(26,26,26,.075)` | 表格行分割、计数带竖分隔——比 `--line` 更淡，密集表格里才不显脏 | 新增 |
| `--line2` | `rgba(26,26,26,.26)` | 输入框描边、次级按钮描边 | 同 |
| `--muted` | `#6B665E` | 次要文字（对白底 5.6:1） | 同 |
| `--faint` | `rgba(26,26,26,.48)` | 占位符、辅助说明 | 同 |
| `--fill` | `#FBFAF7` | 表头底、只读字段底、悬停底 | 新增 |
| `--wash` | `#F5F2EC` | 只读区底、骨架块 | 新增 |
| `--danger-bg` | `#FBF1EC` | 失败提示底 | 沿用登录页错误块 |

页面底色 `--wall` 只铺在内容区与整页背景，卡片保持 `--paper`，卡片带 `0 1px 0 rgba(26,26,26,.02)` 极浅下影——有分离感但不靠重边框。

侧栏深色区专用：底 `--ink`，主文字 `rgba(242,239,233,.74→.92)`，分组标题 `rgba(242,239,233,.36)`，选中底 `rgba(242,239,233,.07)`，分隔线 `rgba(242,239,233,.12)`。原型工具条与侧栏同色 `--ink`，避免出现第三层深色。

### 2.2 字体

| 变量 | 字体栈 | 用途 |
|---|---|---|
| `--f-song` | `"Noto Serif SC", "STZhongsong", "Songti SC", STSong, serif` | 页面标题、区块标题、弹窗标题、空状态标题 |
| `--f-body` | `"Noto Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif` | 正文、表格、表单、按钮 |
| `--f-din` | `"DIN Next LT Pro", "Bahnschrift", "Segoe UI", Arial, sans-serif` | 金额、库存、件数、订单号、页码 |

宋体只用于标题层级，不用于正文与表格——后台的辨识速度优先于气质，标题保留宋体是为了与用户端同源。

### 2.3 字号阶梯

| 尺寸 | 字重 | 行高 | 用途 |
|---|---|---|---|
| 11 | 400 | 1.5 | 表头、标签、辅助说明，字距 `.12em` |
| 12 | 400 | 1.6 | 次级信息、时间戳 |
| 13 | 400 | 1.6 | 正文、表格单元格、按钮 |
| 15 | 400 | 1.6 | 表单输入值 |
| 17 | 500 | 1.4 | 卡片标题、区块标题（宋体） |
| 20 | 500 | 1.35 | 页面内大区块标题（宋体） |
| 26 | 500 | 1.25 | 页面主标题（宋体，字距 `.04em`） |
| 34 | 400 | 1.05 | 计数带数值（DIN，`tabular-nums`，字距 `-.01em`） |

下限 11px，不到 12px 的文字一律不承载操作含义（用户端已确立的规则，后台沿用）。

### 2.4 间距与栅格

4 的倍数，八级：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 页面内边距：`32px 40px 64px`
- 卡片内边距：`20px 24px`
- 卡片间距：`24px`
- 表单字段垂直间距：`20px`；同组内 `12px`
- 12 列栅格，gutter `24px`；内容最大宽 `1560px`

### 2.5 描边、阴影、动效

- 描边一律 `1px solid var(--line)`，不使用双层边框。
- 阴影仅两处：卡片悬停 `0 12px 28px rgba(26,26,26,.08)`；弹窗 `0 24px 64px rgba(26,26,26,.24)`。表格行不加阴影。
- 动效：悬停 `.18s ease`，进入 `.24s cubic-bezier(.22,.61,.36,1)`，退出 `.16s ease`。只动 `background / border-color / color / transform / opacity`。
- `prefers-reduced-motion: reduce` 下所有过渡归零。

### 3.1 整体骨架

```

│              │  顶栏 56  面包屑 · 管理员 · 退出              │
│  侧栏 232    ├────────────────────────────────────────────────┤
│  墨色        │                                                │
│              │  内容区                                        │
│  品牌区 72   │  padding 32 40 64，最大 1560                   │

│  概览        │  │ 面包屑下的 h1 + 一句说明        │            │
│  ──────      │  ├ 工具条 / 筛选条 ──────────────┤            │
│  商品        │  ├ 卡片（表格 / 表单 / 详情）────┤            │
│   分类       │  └────────────────────────────────┘            │
│   商品       │                                                │
│   库存相册   │                                                │
│  ──────      │                                                │
│  顾客        │                                                │
│   账号       │                                                │
│  ──────      │                                                │
│  交易        │                                                │
│   订单       │                                                │
│  ──────      │                                                │
│  系统        │                                                │
│   会话与安全 │                                                │
│  ──────      │                                                │
│  退出        │                                                │
└──────────────┴────────────────────────────────────────────────┘
```

- 外层 `height: 100vh; display: flex; overflow: hidden`，侧栏与内容区各自纵向滚动。整页滚动会让导航跟着走掉，后台必须常驻。
- 侧栏固定 `232px`，`flex: none`；内容区 `flex: 1; min-width: 0`（`min-width: 0` 是表格横滚不撑破布局的关键）。
- 内容区本身不设卡片外框，卡片（`.card`）才是承载表格与表单的容器。

### 3.2 侧栏

| 部分 | 高度 | 规格 |
|---|---|---|
| 品牌区 | 64 | logo 32×32（纸底裁切）+ 主名 12.5px 字距 `.16em` + 副名 10px 字距 `.24em` 色 `.36` |
| 分组标题 | 40 | 10px，字距 `.2em`，`rgba(cream,.36)`，左内边距 18，下沿对齐，不可点击 |
| 导航项 | 38 | 12.5px，左内边距 18，图标 16px + 文字间距 11；悬停底 `.06`；选中：左 2px `--rust` 竖条 + 底 `.07` + 文字 `.92` |
| 底部账号区 | 自适应 | 28×28 姓名首字方块（纸底墨字）+ 显示名 12px + 角色 10px 字距 `.14em` 色 `.36` + 右侧退出图标；上边 `1px rgba(cream,.12)` |

图标统一 16×16，`stroke="currentColor"`，线宽 1.5，圆头端点；不引图标库，内联 SVG。

### 3.3 顶栏

高 `56`，底 `--paper`，下边 `1px solid var(--line)`，左右内边距 `40`。

- 左：面包屑「商品 / 款号维护」，12px，分隔符 `/` 色 `--faint`，末级 `--ink` 不可点。首个面包屑是模块名，点击回模块首页。
- 右：管理员显示名 13px + 角色标记（`ADMIN`，11.5px，与状态标签同一套「方块 + 文字」样式，空心方块表示中性）+ 退出按钮（图标 + 「退出」，高 32，幽灵）。
- 窄屏（<1024）左侧插入汉堡按钮 36×36，面包屑只保留末级。

## 四、信息架构与路由

| 分组 | 导航项 | 路由 | 关键页面 |
|---|---|---|---|
| 概览 | 控制台 | `/admin/console` | 待办与范围 |
| 商品 | 分类维护 | `/admin/categories` | 两级树 + 行内编辑 |
| 商品 | 款号维护 | `/admin/products` | 列表 / 新增 / 编辑 |
| 商品 | 库存与相册 | `/admin/products/{id}/stock`、`/admin/products/{id}/images` | 补货、相册 |
| 顾客 | 账号管理 | `/admin/users` | 列表 / 编辑 / 重置 |
| 交易 | 订单管理 | `/admin/orders` | 列表 / 详情 / 改单 / 发货 |
| 系统 | 会话与安全 | `/admin/security` | 只读策略说明 |

左侧栏只在有权限时渲染，不存在「灰掉不可点」的项——当前版本没做的模块直接不出现，避免暗示。

## 五、页面规范

### 5.1 控制台 `/admin/console`

结构：页标题 → 计数带 → 待办列表 → 系统状态卡。

- **计数带**：一个白卡横切四栏，栏间 `1px var(--hair)` 竖分隔，不做四张独立卡片——四个孤立白盒会让首屏碎掉。每栏 `padding 20 26 22`：指标名 10.5px 字距 `.16em` `--muted`（右侧接一段 `--hair` 细线延伸到栏末），数值 34px `--f-din` 行高 1.05，单位 11.5px `--muted`，脚注 11px `--faint`。四个口径：在售款数、草稿款数、库存 ≤3 的款数、待发货订单数，全部由当次 `COUNT` 得到。
- **待办列表**：无表格线，三列栅格 `76px | 1fr | auto`，行高 56，左：状态标记（方块 + 文字）+ 描述（主行 13px + 次行 11.5px `--muted`），右：进入链接（常态 `--ink` + `--line2` 下划线，行悬停转 `--rust-ink`）。三行的颜色只出现在左列标记上，右侧链接不再成列发橙。无待办时整块换成空状态：「当前没有待处理事项」。
- **系统状态卡**：两列 `dl`，字段为后台端口、会话超时、CSRF 状态、数据库连接。前三个是配置常量，数据库连接由一次 `SELECT 1` 的真实结果决定，失败显示「连接异常」并给排查提示。
- 控制台不放趋势图、不放销售额。没有可核对的数据源就不画。

### 5.2 列表页（分类 / 款号 / 账号 / 订单共用骨架）

结构固定为四段：页标题 → 筛选条 → 表格 → 分页条，全部装在同一个白卡里。

- 页标题：h1 26px 宋体；右侧放主行动按钮（「新增款号」「新增一级分类」）。
- 筛选条：高 64，上下 `1px solid var(--line)`，左内边距 16。
  - 搜索框：宽 260，下划线式（仅底边 `--line2`），左侧 16px 放大镜，`focus` 时底边转 `--ink`。
  - 状态分段器 `.seg`：高 36，`1px solid var(--line)`，项 11.5px 内边距 `0 14`，选中项墨底纸字。
  - 右侧：`重置`（tlink 样式，12px + 下划线）+ 主按钮（高 40 `sm`）。
- 表格：见 6.1。
- 分页条：上边 `1px solid var(--line)`，高 64，左「共 54 条 · 第 1 / 3 页」，右页码组 + 每页条数下拉（10 / 20 / 50，默认 20）。

各列表的列定义：

| 列表 | 列（对齐） | 操作列 |
|---|---|---|
| 分类 | 编码(左)、名称(左，二级缩进 24 + 引导线)、层级(标签)、排序(右)、款数(右) | 编辑、删除 |
| 款号 | 款号(DIN, 左)、缩略图 32×42 + 名称 / 面料(左，同一格)、品类(左)、价格(右, DIN)、库存(右, DIN)、状态(标记) | 编辑 + 「更多」（补货 / 相册 / 上下架） |
| 账号 | 用户名(左)、显示名(左)、邮箱(左)、状态(标签)、注册时间(右, DIN) | 编辑、重置口令、启停 |
| 订单 | 订单号(DIN, 左)、收货人(左)、金额(右, DIN)、状态(标签)、下单时间(右, DIN) | 详情、发货 |

- 操作列宽 `96`，右对齐。**只保留一个主行动**（编辑 / 详情），其余收进「更多」（`···`，24×24，`<details>` 实现，无脚本）。一列四个橙色链接会把整行数据压成背景，这是要避免的。
- 主键列（款号、订单号、用户名）本身是链接，点击进详情；不额外加「查看」。
- 缩略图与名称同格（`.pcell`，flex，间距 14），不进独立列：独立列会让名称列拿到全部剩余宽度，左侧空出一大块。
- 窄屏（<1024）隐藏「品类」「库存」两列，表格不再横滚。

### 5.3 商品编辑 `/admin/products/{id}`

两栏：主列 `minmax(0,1fr) max 760`，侧列 `320`，间距 24。

- 主列卡片 1「基本信息」：款号（创建后只读）、名称、二级分类（`select`）、价格、排序。
- 主列卡片 2「面料与工艺」：面料、克重、版型、工艺，均 `textarea` 3 行，纯文本，保留换行，字数上限标注在右下（如 `120 / 400`）。
- 主列卡片 3「商品文案」：描述，`textarea` 6 行。
- 侧列卡片 1「状态」：上架/草稿分段器 + 当前状态说明 + 保存按钮（`wide`）。
- 侧列卡片 2「库存」：当前库存大号 DIN + 「库存只能通过补货入口调整」11.5px + 「去补货」链接；该字段在编辑表单里**不出现可输入框**，避免绝对赋值。
- 侧列卡片 3「相册」：3 张缩略图 72×96 + 数量 + 「维护相册」链接。
- 侧列卡片 4「元信息」：创建时间、更新时间、`version`（只读小字，供排查版本冲突）。
- 底部操作条：放在滚动容器**之外**（`.shell` 内、`.main` 之后），高 64，白底上边线，左「修改仅在点击保存后生效」11.5px 提示，右「取消」「保存修改」。不采用 `position: sticky`——sticky 会盖住表单内容，放在滚动区外由 flex 布局自动让出高度，永不遮挡。

新增与编辑同一模板，差异：新增时款号可填、侧列无「相册」「元信息」两张卡。

### 5.4 补货 `/admin/products/{id}/stock`

独立小页，宽度 `560`，不套两栏。

- 三行只读事实：当前库存（DIN 30px）、最近一次补货时间、`version`。
- 一个输入：补货数量，`type="number" min="1" step="1"`，右侧显示「补货后 → 13」实时预览（前端 `input` 事件计算，服务端仍独立校验）。
- 提交按钮「确认补货」。非正整数就地提示「补货数量需为正整数」，不提交。
- 说明：补货为增量语义，不覆盖当前库存；并发时以 `version` 条件更新，失败提示「商品已被其他操作更新，请重新加载」。

### 5.5 相册 `/admin/products/{id}/images`

- 上：新增一行表单（图片路径、图片类型：平铺 / 上身 / 细节、来源说明、排序）。
- 下：现有相册列表，每行 72×96 缩略图 + 路径 + 类型标签 + 排序 + 「上移 / 下移 / 删除」。排序用按钮交换，不引入拖拽库。
- 空相册：提示「未维护相册时，用户端回退使用封面；封面缺失再用缺省图」。

### 5.6 账号编辑 `/admin/users/{id}`

- 字段：用户名（只读）、角色（只读标签）、显示名、邮箱、电话。
- 三个独立动作，不与保存混在一起：`保存信息`、`重置口令`（弹窗二次确认）、`停用 / 启用`（弹窗，写明后果：「停用后该账号当前会话在下一次请求即失效」）。
- 重置口令弹窗内不显示新口令输入框，只说明「重置为统一初始教学口令，并要求本人首次登录后修改」；结果以提示条告知。

### 5.7 订单详情 `/admin/orders/{orderNo}`

- 顶部状态条：订单号（DIN）+ 状态标签 + 主行动（`发货` 仅 `PAID` 出现，其余状态不渲染按钮）。
- 左：明细快照表（款号、名称、单价、数量、小计），底部合计行，金额右对齐 DIN，强调合计。
- 右：收货信息卡（三项，`PENDING_PAYMENT` / `PAID` 时出现「修改」按钮）+ 支付信息卡（凭证号、支付方式、支付时间；未支付显示「—」）+ 时间线（下单 / 支付 / 发货）。
- 删除入口只在「已取消且无支付凭证」时出现，红字文字按钮，弹窗二次确认。

### 5.8 会话与安全 `/admin/security`

只读页，不改系统配置。四组事实：会话 Cookie 名与端口、超时 30 分钟、CSRF 令牌作用范围、口令存储方式（BCrypt，不可逆）。每组一句话说明「为什么这样设定」，不写代码路径与类名。

## 六、组件规范

### 6.1 表格 `.tbl`

| 项 | 规格 |
|---|---|
| 表头 | 高 42，10.5px，字距 `.14em`，`--muted`，底 `--fill`，下边 `1px --line`，`sticky top: 0` |
| 行 | 高 60（含 32×42 缩略图）；无图列表可收到 52 |
| 单元格内边距 | `0 16`，首列左 `24`，末列右 `24` |
| 行分割 | 仅横向 `1px var(--hair)`（`rgba(26,26,26,.075)`）；首行下方有、末行下方无 |
| 悬停 | 整行底 `--fill`，`.14s` |
| 数字 | `--f-din` + `font-variant-numeric: tabular-nums`，右对齐，金额固定两位小数与 ¥ |
| 空表 | 保留表头，空状态占一整行，高 240 |
| 横滚 | 容器 `overflow-x: auto`，表格 `min-width: 760`；表格外不出现整页横滚 |

不使用斑马纹：分割线已经足够，斑马纹与细边同时出现会显脏。

### 6.2 状态标签 `.tag`

状态不用描边方框，用「5px 方块 + 文字」：一列表格里八个描边小框会变成满屏花纹，方块标记的信息量相同而视觉噪音低一个量级。

| 语义 | 方块 | 文字 | 用于 |
|---|---|---|---|
| 进行中 | `--rust` 实心 | `--rust-ink` | 在售、已支付、待发货 |
| 完成 | `--ink` 实心 | `--ink` | 已发货、已完成 |
| 草稿 / 中性 | `--faint` 实心 | `--muted` | 草稿、待支付、已启用 |
| 终止 | 1px `--faint` 空心 | `--faint` | 已取消、已停用、已售罄 |
| 需要处理 | `--rust` 实心 + `0 0 0 2px rgba(180,100,58,.16)` 光圈 | `--rust-ink` | 低库存、库存 0 但在售 |

高 `20`，无内边距无边框，标记与文字间距 7，字号 11.5px，字距 `.04em`。同级并排时间距 ≥ 20，否则相邻标签的界线会消失。

### 6.3 按钮

沿用用户端语汇，只做尺寸收敛：

| 尺寸 | 高 | 内边距 | 字号 | 场景 |
|---|---|---|---|---|
| `lg` | 48 | `0 30` | 13 | 登录、弹窗主行动 |
| `md` | 40 | `0 20` | 13 | 页面级主行动 |
| `sm` | 32 | `0 14` | 12 | 表格行内、工具条 |
| 图标按钮 | 32×32 | — | — | 关闭、汉堡、上下移 |

- 主：墨底纸字，悬停转 `--rust`，按下转 `--rust-ink`，**不做位移**——后台是密集点击场景，按钮浮动会让手指和视线一起抖。
- 次：透明底 + `1px --line2`，悬停边转 `--ink`，字转 `--rust-ink`。
- 危险：`--rust` 底纸字，仅用于确认删除类弹窗。
- 禁用：底 `--line`，字 `--paper`，`cursor: not-allowed`，悬停不变。
- `focus-visible`：`outline 2px --rust; outline-offset 2px`。

### 6.4 表单

- 标签：11.5px，字距 `.12em`，`--muted`，与输入间距 8。必填在标签后加 `--rust` 星号，并提供 `sr-only` 的「必填」。
- 输入：高 40，`1px --line2`，底 `--paper`，内边距 `0 12`，字号 13；`focus` 时边框 `--ink`，并保持内边距不变（用 `box-shadow: inset 0 0 0 1px` 补内环，避免尺寸跳动）。
- 文本域：`min-height 84`，可纵向拉伸，不可横向。右下角字数计数 11px `--faint`。
- 只读：底 `--wash`，字 `--muted`，右侧 11px 说明来源（「创建后不可改」「由补货入口调整」）。
- 错误：边框 `--rust-ink`，下方 11.5px `--rust-ink` 文案，输入框加 `aria-invalid="true"` 与 `aria-describedby`。
- 字段组：主列内单列排布，宽字段（名称、地址）全宽，窄字段（价格、排序）`max-width 220` 并两列并排。

### 6.5 弹窗 `.modal`

- 原生 `<dialog>`，不引脚本库。宽 480（小号 400），白底，直角，内边距 28。
- 遮罩 `rgba(26,26,26,.52)`，点击遮罩关闭（除破坏性操作，需显式点按钮）。
- 标题 20px 宋体；正文 13px，行高 1.7；底部按钮右对齐，间距 12，次要在左、主行动在右。
- 打开：焦点落在首个输入或「取消」；ESC 关闭；关闭后焦点回到触发按钮。
- 破坏性文案必须写明后果，不写「确定吗？」这种无信息量的问句。

### 6.6 状态提示 `.alert`

| 类型 | 底 | 左条 | 字 | 图标 | 角色 |
|---|---|---|---|---|---|
| success | `#EFEBE3` | `--ink` | `--ink` | 勾 | `role="status"` |
| error | `#FBF1EC` | `--rust` | `#8A3F1E` | 叹号 | `role="alert"` |
| info | `--fill` | `--faint` | `--body` | 圆点 | `role="status"` |

高 auto，内边距 `12 16`，左 3px 实条，无圆角，位于页标题与内容之间，间距 24。不自动消失（读屏会错过），右侧留 36×36 关闭按钮。同一页面只出现一条，多条结果合并成一条列出。

### 6.7 空状态 `.empty`

- 居中，上下内边距 72，最大宽 420。
- 标题 20px 宋体；说明 13px `--muted`，行高 1.9；主行动按钮（md）。
- 分两类文案：**无数据**（「还没有款式」+ 新增按钮）与**无结果**（「没有符合条件的记录」+ 「清除筛选」）。两者语义不同，不能共用一句话。

### 6.8 加载态

- 表格：6 行骨架，每行左 40×40 方块 + 60% 与 30% 两条 12 高块，底 `--wash`，整块 1s 淡入，不做闪烁动画（闪烁在低端屏会抖）。
- 按钮：点击后禁用，文案改为「保存中」，保留原宽度（`min-width` 固定）避免按钮收缩导致误点。
- 页面级：顶部 2px `--rust` 进度条，只用于跨页提交，不用于局部刷新。

### 6.9 面包屑与页标题

- 面包屑 12px，`--faint` 分隔，末级 `--ink` 且 `aria-current="page"`。
- 页标题下方一句说明（13px `--muted`，最大宽 720），写当前页能做什么，不写模块背景。

## 九、可访问性

1. 每页首个可聚焦元素是「跳到主要内容」，目标 `#main`，聚焦时落在左上角。
2. 侧栏当前项 `aria-current="page"`；分组标题用 `<h2 class="side__group">`，构成页面大纲。
3. 表格带 `<caption class="sr-only">` 说明数据范围；操作列按钮写全「编辑 FL-HM-01」而非只有「编辑」，供读屏区分。
4. 状态变化用 `aria-live="polite"`（成功）与 `role="alert"`（失败）。
5. 全部功能可键盘完成：Tab 顺序=侧栏→顶栏→内容；弹窗内 Tab 循环；ESC 关闭。
6. 对比度：正文 `--ink` 对白底 16.1:1；`--muted` 5.6:1；`--rust-ink` 对纸底 4.77:1。`--rust` 只用于 ≥16px 文字或非文字（竖条、边框），不用于小字。
7. 图片缩略图 `alt` 写款号与名称，不写「图片」。窄屏隐藏列时，被隐藏列的信息在详情页必须仍可查到。
